About The Project

Custom Media Platform Showcase is a high-performance, responsive single-page architecture built for dynamic audio streaming, automated asset processing, and modular UI component delivery.

  • ⚡ Modular Frontend

    Built with zero-dependency Vanilla JS SPA router, class-based architecture, and SCSS fluid typography (clamp()) for smooth responsive scaling.

  • 🎧 Dynamic Audio Pipeline

    Custom JSON payload parser integration for Bandcamp audio streams, featuring embedded iframe controls and HTML5 fallback player support.

  • 🛠️ Automated Build Tools

    Node.js CLI automation leveraging Sharp and FFmpeg to transcode WebM/MP4 video variants and build responsive WebP images on the fly.

  • 🧪 Production QA & CI

    Comprehensive testing suite using Vitest and Playwright (E2E), enforced via ESLint flat configs, Prettier, and Husky pre-commit hooks.
